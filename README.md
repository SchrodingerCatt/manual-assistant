# 📚 სასწავლო ასისტენტი (RAG + Gemini + Flask, streaming)

AI ჩატბოტი მე-7 კლასის მოსწავლეებისთვის — **გეოგრაფიისა და მათემატიკის**
სახელმძღვანელოებზე დაფუძნებული, გადასართავი ღილაკებით. პასუხობს **მხოლოდ**
შესაბამის სახელმძღვანელოზე დაყრდნობით (Retrieval-Augmented Generation),
მუშაობს **სოკრატული მეთოდით** (არ იძლევა მზა პასუხს, სვამს დამაზუსტებელ
კითხვებს) და პასუხს წერს **streaming**-ით — ისე, როგორც ChatGPT/Gemini.

## არქიტექტურა

- **ფრონტენდი**: ერთი HTML ფაილი (`static/index.html`), CSS და JS მასშივეა.
- **ბექენდი**: მსუბუქი Flask სერვერი (`app.py`), რომელიც ინახავს API
  გასაღებს სერვერის მხარეს და streaming-ით აბრუნებს პასუხს.
- **RAG**: თითოეულ საგანს (გეოგრაფია, მათემატიკა) თავისი, სრულიად
  იზოლირებული FAISS ინდექსი აქვს — ისინი ერთმანეთს არასდროს ერევა.

**რატომ არის საჭირო Flask ბექენდი, თუ ფრონტენდი ერთი HTML ფაილია?**
თუ Gemini-ს გამოძახება პირდაპირ ბრაუზერიდან (JavaScript-იდან) მოხდებოდა,
API გასაღები ყველასთვის ხილული იქნებოდა გვერდის კოდში — ნებისმიერს
შეეძლებოდა მისი მოპარვა და თქვენი ბიუჯეტის ხარჯვა. ამიტომ გასაღები
ცხოვრობს მხოლოდ სერვერზე (`config.py`), ბრაუზერი კი მხოლოდ ტექსტურ
პასუხს ღებულობს.

## რას აკეთებს ბოტი

- პასუხობს მხოლოდ აქტიური საგნის სახელმძღვანელოზე დაყრდნობით.
- მუშაობს სოკრატული მეთოდით: სვამს დამაზუსტებელ კითხვებს, შლის ამოცანას
  ეტაპებად, უთითებს შეცდომაზე და აძლევს მოსწავლეს საშუალებას თავად
  მივიდეს პასუხამდე — მზა პასუხს არ იძლევა, განსაკუთრებით ამოცანებზე.
- ეხმარება მასალის გამეორებაში, ტერმინების ახსნაში, დამატებითი
  მაგალითების მოძებნაში (ამ შემთხვევებში პირდაპირ და გასაგებად პასუხობს).
- პასუხის ბოლოს უთითებს სახელმძღვანელოს გვერდის ნომერს/ნომრებს, საიდანაც
  ინფორმაცია აიღო (დეტერმინისტულად ემატება, არა LLM-ის იმედად).
- პასუხს წერს streaming რეჟიმში — ტექსტი ჩნდება ეტაპობრივად, არა ერთბაშად.

## რას არ აკეთებს

  პასუხობს (მათ შორის — გეოგრაფიის რეჟიმში მათემატიკის კითხვებს და პირიქით).
- არ აფასებს მოსწავლეს, არ ავსებს ჟურნალს, არ ცვლის მასწავლებელს.

  საუბარი ცოცხლობს მხოლოდ მიმდინარე ბრაუზერის სესიაში (JS მეხსიერებაში)
  და იკარგება გვერდის განახლებისას.
- არ აქვს სურათების/ფაილების ატვირთვის ფუნქციონალი.

## 1. ლოკალური გაშვება

```bash
git clone <თქვენი-repo-ბმული>
cd geo-rag-chatbot

python3 -m venv .venv
source .venv/bin/activate        # Windows-ზე: .venv\Scripts\activate

pip install -r requirements.txt
```

**API გასაღების დაყენება:**

```bash
cp .env.example .env
```

გახსენით `.env` და ჩაწერეთ თქვენი გასაღები
([Google AI Studio](https://aistudio.google.com/apikey)-დან):

```
GOOGLE_API_KEY=თქვენი_რეალური_გასაღები
```

**წიგნების დამატება:**

მოათავსეთ ორივე PDF საქაღალდეში `data/` ზუსტად ამ სახელებით:
- `გეოგრაფია.pdf`
- `მათემატიკა.pdf`

**ინდექსების აგება** (ორივე საგნისთვის ერთდროულად):

```bash
python3 ingest.py
```

ან მხოლოდ ერთი საგნისთვის (მაგ. წიგნის განახლების შემდეგ):

```bash
python3 ingest.py math
python3 ingest.py geography
```

**გაშვება:**

```bash
python3 app.py
```

ბრაუზერში გაიხსენით: `http://localhost:5000`

## 2. GitHub-ზე ატვირთვა

`.gitignore` უკვე იცავს:
- `.env` (რეალური API გასაღები) — არასდროს აიტვირთება.
- `data/*.pdf` და `vectorstore/` (ორივე საგნის PDF და ინდექსები) —
  საავტორო მასალაა, არ არის რეკომენდებული საჯარო რეპოზიტორიაში.

```bash
git init
git add .
git commit -m "Multi-subject Socratic RAG chatbot"
git branch -M main
git remote add origin <თქვენი-repo-ბმული>
git push -u origin main
```

**ატვირთვამდე გადაამოწმეთ**, რომ `.env` არ ჩანს `git status`-ში.

## 3. ჰოსტინგი

ეს არის ერთიანი Flask აპლიკაცია (ფრონტენდიც და API-ც ერთად), ამიტომ
საჭიროა პლატფორმა, რომელსაც შეუძლია Python პროცესის გაშვება (არა
სტატიკური hosting, როგორიცაა GitHub Pages).

**Render.com (რეკომენდებული, უფასო tier):**
1. შექმენით ახალი **Web Service**, დააკავშირეთ GitHub რეპოზიტორია.
2. Build command: `pip install -r requirements.txt && python3 ingest.py`
3. Start command: `python3 app.py`
4. **Environment**-ში დაამატეთ `GOOGLE_API_KEY` საიდუმლო ცვლადად.
5. ატვირთეთ PDF ფაილები `data/`-ში ცალკე (repo-ს გარეთ დატოვეთ, თუ
   საჯაროა) — Render-ის დისკზე ხელით ატვირთვა ან `data/`-ს
   `.gitignore`-დან ამოღება, თქვენი გადაწყვეტილებაა.

**Railway.app / Fly.io** — იგივე პრინციპი: Python გარემო, `GOOGLE_API_KEY`
Secrets/Environment Variables-ში, build-ზე `ingest.py`-ის გაშვება.

## პროექტის სტრუქტურა

```
geo-rag-chatbot/
├── app.py               # Flask სერვერი: /, /api/subjects, /api/chat (streaming)
├── rag_engine.py         # რეტრივალი + სოკრატული სისტემური prompt + Gemini streaming
├── ingest.py             # PDF -> chunks -> FAISS ინდექსი (თითო საგანზე)
├── config.py             # კონფიგურაცია + საგნების განსაზღვრა
├── static/
│   └── index.html        # ერთიანი ფრონტენდი (HTML+CSS+JS)
├── requirements.txt
├── .env.example
├── .gitignore
├── data/                 # აქ მოათავსეთ გეოგრაფია.pdf და მათემატიკა.pdf
└── vectorstore/
    ├── geography/         # გეოგრაფიის FAISS ინდექსი
    └── math/               # მათემატიკის FAISS ინდექსი
```
